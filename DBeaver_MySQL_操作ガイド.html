DBeaverでMySQLのテーブル・データを確認する操作ガイド

対象：DBeaverデスクトップ版を使い始めた方（Windowsの操作を基準）
確認日：2026年9月7日

メニュー名は日本語と英語を併記しています。バージョン・言語・画面設定によって名称や配置が異なることがあります。左側の接続ツリーは「データベースナビゲータ（Database Navigator）」または「Connections」と表示されます。

1. まずテーブルのデータを表示する

MySQLへの接続が登録済みの場合は、この手順から始められます。

  1. DBeaverを起動します。
  2. 左側の接続ツリーで、対象のMySQL接続を展開します。未接続の場合は、接続を右クリックして「接続（Connect）」を選びます。
  3. 対象データベースを展開し、「テーブル（Tables）」を開きます。
  4. 見たいテーブルをダブルクリックします。
  5. 開いた画面の「データ（Data）」タブを選びます。
  6. 行と列からなる表が表示されれば、データを確認できます。

接続ツリーの例（フォルダ構成は設定によって異なります）：

MySQL接続
└─ データベース（Databases）
   └─ sample_db
      ├─ テーブル（Tables）
      │  ├─ users
      │  └─ orders
      └─ ビュー（Views）

テーブルの右クリックメニューに「データを表示（View Data）」がある場合は、そこから開くこともできます。

覚える操作：接続 → データベース → Tables → テーブル → Data

参考：接続ツリーの操作、データエディタ

2. MySQLへの接続を新しく登録する

2.1 接続情報を用意する

項目 入力例 説明
ホスト（Host） localhost MySQLサーバーのホスト名またはIPアドレス。localhostは自分のPCです
ポート（Port） 3306 MySQLの一般的なポート。指定があればその番号を使います
データベース（Database） sample_db 接続したいデータベース名
ユーザー名（Username） app_reader 接続用のMySQLユーザー
パスワード（Password） 管理者から案内された値 接続用パスワード

上記は例です。実際の接続先の情報に置き換えてください。DBeaverをインストールしただけではMySQLサーバーは作成されません。

2.2 接続を作成する

  1. 「新しい接続（New Database Connection）」ボタンをクリックします。見つからない場合は「ファイル（File）」→「新規（New）」からデータベース接続を選びます。
  2. MySQL用ドライバーを選び、「次へ（Next）」をクリックします。MySQL 8以降では通常「MySQL」を選びます。古いサーバーでは対応するドライバーを選んでください。
  3. ホスト、ポート、データベース、ユーザー名、パスワードを入力します。
  4. 「接続テスト（Test Connection）」をクリックします。
  5. 初回にドライバーのダウンロードが求められたら、案内に従います。
  6. 接続成功を確認し、「完了（Finish）」をクリックします。

SSH・SSL接続が必要な環境では、管理者から指定された設定も入力します。

参考：接続の作成、MySQL接続設定

3. テーブルの構造を確認する

データの中身は「Data」、列の定義は「プロパティ（Properties）」などの構造表示で確認します。

  1. 接続ツリーでテーブルをダブルクリックします。
  2. 「Properties」などの構造を表示するタブを開きます。
  3. 「カラム（Columns）」を選び、列名やデータ型を確認します。
  4. 必要に応じて「制約（Constraints）」「外部キー（Foreign Keys）」「インデックス（Indexes）」も確認します。
表示項目 見るポイント
列名 id、name、created_atなど、保存される項目の名前
データ型 INTは整数、VARCHARは文字列、DATETIMEは日時など
NOT NULL 値を未設定のNULLにできるか
デフォルト値 INSERT時に列を省略した場合などに使われる値
主キー（Primary Key） 行を一意に識別する列
外部キー（Foreign Key） 他のテーブルとの参照関係
インデックス（Index） 検索などに利用される索引

「DDL」タブがある場合は、テーブル定義のSQLも確認できます。SQLで確認する方法は第7章に記載しています。

参考：データベースオブジェクトエディタ

4. データ画面の見方

場所・項目 用途
列の見出し カラム名の確認
各行 1件ずつのレコードの確認
上部のフィルター入力欄 条件に合う行だけ表示
Refresh（更新） データを再取得
取得件数・結果件数の表示 現在取得した行数などの確認
Valueパネル 長い文字列など、セルの内容の確認

表示中の行数がテーブル全体の件数とは限りません。 DBeaverはデータを分割して取得します。続きが必要な場合は、追加取得の操作を使います。「Fetch all data（全データ取得）」は、大きいテーブルでは時間やメモリを多く使うため、先に条件で絞り込むと扱いやすくなります。

NULLは「値がない」ことを表し、空文字列や数値の0とは異なります。

参考：データエディタ

5. 条件を指定してデータを絞り込む

以下は、対象テーブルにid、name、status、created_at、email列がある場合の例です。実際の列名に置き換えてください。

5.1 フィルター欄に条件を入力する

  1. テーブルの「Data」タブを開きます。
  2. 表の上にあるSQL条件用のフィルター欄に、次のような条件を入力します。
  3. Enterキー、または「フィルター適用（Apply filter criteria）」を押します。
id = 100

ここには通常、SELECTやWHEREを付けずに条件部分だけを書きます。

やりたいこと 入力する条件
IDが100の行 id = 100
名前が田中の行 name = '田中'
名前に田中を含む行 name LIKE '%田中%'
ステータスがactiveの行 status = 'active'
2026年9月1日以降の行 created_at >= '2026-09-01'
メールアドレスがNULLの行 email IS NULL
2つの条件を満たす行 status = 'active' AND id >= 100

文字列・日付はシングルクォートで囲みます。NULLの判定には= NULLではなくIS NULLを使います。

5.2 セルの値を使って絞り込む

  1. 条件に使いたい値のセルを右クリックします。
  2. 「Filter by value」または「Order / Filter」に相当するメニューを開きます。
  3. 選択した値と一致する条件などを選び、適用します。

5.3 条件を解除する

フィルター欄の条件を削除してEnterキーを押します。並び順も含めて解除したい場合は「Remove all filters/orderings」を使います。

参考：データのフィルター

6. 並び替え・再読み込み・コピー

並び替え

セルの右クリックメニューや列のメニューから「Order / Filter」を開き、対象列のASC（昇順）またはDESC（降順）を選びます。例えばIDの大きい順に見るにはid DESCを指定します。

複数列の順序を明確に指定したい場合は、第7章のSQLのORDER BYを使うと確認しやすくなります。

参考：フィルターと並び替え

最新データへの更新

データ画面の「Refresh（更新）」をクリックします。テーブル一覧自体を更新したいときは、左側の接続ツリーで「Tables」やデータベースを右クリックし、「Refresh」を選びます。

コピー

必要なセル範囲を選択し、Ctrl+Cでコピーします。列名付きなどの形式が必要なら、右クリックメニューのコピー関連項目を確認します。まとまったデータを保存する場合は、第8章のエクスポートを使います。

参考：データエディタ、接続ツリー

7. SQLを書いてデータを確認する

7.1 SQLエディタを開く

  1. 左側の対象接続、または対象データベースを右クリックします。
  2. 「SQLエディタ（SQL Editor）」から「新しいSQLスクリプト（New SQL Script）」などを選びます。
  3. エディタ上部の接続先が正しいことを確認します。
  4. SQLを入力し、実行したい文の中にカーソルを置いてCtrl+Enterを押します。
  5. 下部の結果（Results）を確認します。

文字列を選択している場合は、その選択部分が実行対象になります。最初は1文ずつ実行すると結果を追いやすくなります。

参考：SQLエディタ、SQLの実行

7.2 よく使う参照SQL

sample_dbとusers、列名は例です。自分のデータベース名・テーブル名・列名に置き換えてください。これらの例は既存データの確認用で、テーブルやデータは作成しません。

-- 現在選択されているデータベースを確認（未選択ならNULL）
SELECT DATABASE();

-- 自分の権限で表示できるデータベースの一覧
SHOW DATABASES;

-- 指定したデータベースのテーブル・ビュー一覧
SHOW TABLES FROM sample_db;

-- テーブルの列定義
SHOW COLUMNS FROM sample_db.users;

-- テーブルの作成定義
SHOW CREATE TABLE sample_db.users;

-- ID順に最大100件を表示
SELECT *
FROM sample_db.users
ORDER BY id
LIMIT 100;

-- 必要な列だけ表示
SELECT id, name, email
FROM sample_db.users
ORDER BY id
LIMIT 100;

-- 条件に一致するデータを表示
SELECT id, name, status
FROM sample_db.users
WHERE status = 'active'
ORDER BY id DESC
LIMIT 100;

-- 作成日時が新しい順に表示。同時刻ならIDの大きい順
SELECT id, name, created_at
FROM sample_db.users
ORDER BY created_at DESC, id DESC
LIMIT 100;

-- テーブル全体の件数
SELECT COUNT(*) AS total_count
FROM sample_db.users;

-- 条件に一致する件数
SELECT COUNT(*) AS active_count
FROM sample_db.users
WHERE status = 'active';

LIMIT 100は結果を最大100件に制限します。ORDER BYを付けない場合、表示順は保証されません。COUNT(*)は画面の取得件数とは別に件数を調べますが、大きいテーブルでは時間がかかる場合があります。

データベース名を含めたsample_db.usersの形式を使うと、データベース未選択によるエラーを避けやすくなります。

8. 表示したデータをCSVファイルに保存する

  1. 保存対象のテーブルの「Data」タブ、またはSQLの結果を開きます。
  2. 表の中を右クリックし、「データのエクスポート（Export Data）」を選びます。
  3. 形式で「CSV」を選び、「次へ（Next）」に進みます。
  4. 出力対象の列と、データの抽出範囲・取得方法を確認します。
  5. ヘッダー出力、区切り文字、文字コードなどを指定します。日本語を扱う場合はUTF-8が選択肢になります。
  6. 保存フォルダとファイル名を指定します。
  7. 設定内容を確認して実行し、作成したCSVを開いて列名・日本語・出力件数を確認します。

画面に表示済みの行だけを出力するのか、追加取得を含む結果全体を出力するのかは、抽出設定によって異なります。範囲を明確にしたい場合は、WHEREやLIMITを指定したSQLの結果からエクスポートしてください。

参考：データのエクスポート

9. 表示できないときの確認ポイント

症状 確認すること・対処
接続できない ホスト、ポート、ユーザー名、パスワードを確認し、接続テストを実行
Connection refused / タイムアウト MySQLの起動状態、接続先、VPN・SSHの必要性、ネットワークの到達性を確認
Access denied 認証情報と、そのユーザーに接続元からのアクセスが許可されているかを確認
データベースが見えない 接続先、接続設定のDatabase、表示フィルター、閲覧権限を確認
テーブルが見えない 対象データベースを開き直し、Tablesを更新。名前のフィルターと権限も確認
テーブルを開いてもデータが出ない PropertiesではなくDataタブを選択
データが0件になる フィルターを解除し、SQLのWHERE条件や接続先を確認
一部の行しか見えない 取得件数の上限やSQLのLIMITを確認
No database selected データベース名.テーブル名で指定、またはエディタで対象データベースを選択
Table doesn't exist データベース名とテーブル名、必要に応じて大文字・小文字を確認
Unknown column PropertiesのColumnsで実際の列名を確認
フィルターで構文エラー WHEREを付けていないか、文字列をシングルクォートで囲んでいるかを確認
更新しても値が変わらない フィルター、接続先、更新元のコミット状況、現在のトランザクション状態を確認

10. 閲覧時に知っておくとよいこと

Data画面ではセルの編集もできます。「Save」はデータの変更を保存する操作です。誤って編集した場合は、保存する前に「Cancel」で未保存の変更を取り消します。閲覧だけなら、セルの内容を変更したり保存したりする必要はありません。

参考：データエディタの保存・取消
